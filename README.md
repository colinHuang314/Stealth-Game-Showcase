# Stealth-Game-Showcase

Unity stealth game (team of 5, UCSC CMPM 125, 2026) A 3-level stealth game where guards patrol, chase, and return to their routes. My role: guard AI (patrol → chase → return state machine driving NavMesh agents, with raycast vision cones), player movement and custom camera, and debugging NavMesh, terrain, occlusion culling, and UI scaling across machines. Source code is private per course policy.
